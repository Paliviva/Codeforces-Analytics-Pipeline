# Codeforces Clawer

## 项目简介

本程序利用 Codeforces 官方 API，抓取用户比赛信息，并进行数据统计与可视化展示。支持单用户详细分析和多用户批量对比。

## 开发环境

* Windows 10/11

* Visual Studio 2022

* C++17

* libcurl (已包含)

* cJSON (已包含)

## 编译方法

1. 使用 Visual Studio 2022 打开 `OYSQ.sln`。

2. 确保项目属性中的包含目录和库目录已正确指向 `third_party` 和 `libs`。

3. 按 `Ctrl+Shift+B` 生成解决方案。

## 使用方法

1. 运行生成的 `OYSQ.exe`。

2. 选择模式：

   * 模式1：单用户，输入 Codeforces 用户名，生成该用户的详细报告。

   * 模式2：多用户，从 `users.txt` 读取用户名列表，批量生成报告，并生成总览页面 `index.html`。

3. 报告保存在程序运行目录下（如 `handle_report.html`）。

## 功能清单

### 基本功能

* [x] 读取用户 ID

* [x] 抓取比赛列表及用户参赛记录

* [x] 抓取排名、总分、各题得分

* [x] 抓取提交记录，判定赛后补题

* [x] 统计当前等级分、头衔、头像、比赛次数、最高分、近180天数据

* [x] 用户 ID 及 Rating 按 CF 规则着色

* [x] 按时间倒序展示比赛详情表格（含各题得分、补题标记）

### 选做功能

* [x] 多用户支持：从 `users.txt` 读取列表，生成总览页，点击用户名跳转个人报告。

* [x] 题目难度直方图：统计全部与近180天 AC 题目难度分布，双柱对比展示。

## 技术亮点

* **本地缓存**：对 `contest.standings` 数据进行本地持久化，二次运行速度提升十倍，同时遵守 API 限流。

* **赛后补题智能判定**：通过提交时间与比赛结束时间对比，自动标记补题情况。

* **模块化架构**：网络层、解析层、统计层、渲染层分离，便于维护和扩展。

* **跨平台编码处理**：生成 UTF-8 BOM 的 HTML，确保中文不乱码。
